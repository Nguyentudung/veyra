# Writing tools

Tools run as ordinary Lua chunks. Register callbacks with `veyra.on`; query tables with `veyra.get_playback_info()` and `veyra.get_statistics()`. User-created tools belong in the top-level `tools/` directory during development, or the configuration `veyra/tools/` directory after installation. Pre-written player command examples are in `src/player/`. Keep callbacks short because they execute serially on the single scripting thread. Use `veyra.log` to report results to the launch terminal. For an ad-hoc check, open **Lua console** and run `veyra.benchmark()`; it prints the same current performance fields shown in Info.
